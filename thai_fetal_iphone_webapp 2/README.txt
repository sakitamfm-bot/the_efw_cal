Thai Fetal Growth - iPhone web app
=================================
1. Upload this whole folder to an HTTPS web address (hospital intranet server
   with HTTPS, GitHub Pages, Netlify, etc.). Keep the files together.
2. On the iPhone open that address in Safari.
3. Tap Share -> Add to Home Screen -> Add.
4. Open it once from the home screen while online. After that it works with
   no network (flight mode).
Scans are stored only on that iPhone. Use Export CSV to keep or move them.
Updating: replace the files on the server; phones update next time they open
the app online.
